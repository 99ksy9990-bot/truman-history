# 트루먼 역사 발표 자료

해리 S. 트루먼의 주요 결정과 한국전쟁을 다룬 역사 발표 자료입니다.

## 파일

- `index.html` - 웹에서 바로 보는 7면 발표 자료
- `트루먼_3분30초_발표_지면형.html` - 원본 파일명으로 보관한 HTML
- `트루먼_3분30초_발표_지면형.pdf` - 7면 발표 자료 PDF
- `트루먼_발표대본_3분30초.pdf` - 3분 30초 발표 대본 PDF

## 바로가기

- 웹 발표: https://truman-history.vercel.app
- 발표 자료 PDF: https://truman-history.vercel.app/slides.pdf
- 발표 대본 PDF: https://truman-history.vercel.app/script.pdf

화면은 16:9 비율에 맞춰 제작되었습니다. 웹 배포본(`index.html`)은 사진과 글꼴을 `assets/`에서 불러오고, `트루먼_3분30초_발표_지면형.html`은 사진과 글꼴을 모두 담은 단독 파일입니다.

## 휴대폰에서 보기

- 휴대폰을 세로로 들어도 지면이 자동으로 가로로 돌아가 화면을 채웁니다. 밀어서 지면을 넘기고, 화면을 누르면 메뉴가 나타납니다.
- 아이폰 Safari는 웹페이지 전체화면 전환을 지원하지 않습니다. 공유 → 홈 화면에 추가로 설치한 뒤 홈 화면 아이콘으로 열면 주소창 없이 전체화면으로 표시됩니다.
- 글꼴(`assets/chosun.woff2`)은 페이지에 쓰인 글자만 담은 조선신명조 부분 글꼴입니다. 새 글자를 넣으면 원본 `ChosunSm.TTF`에서 다시 만들어야 합니다.
